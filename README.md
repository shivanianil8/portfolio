- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom engineering theme
- **Animations & Physics**: [Framer Motion](https://www.framer.com/motion/)
- **Routing**: [React Router DOM v7](https://reactrouter.com/)
- **Iconography**: [Lucide React](https://lucide.dev/)
- **Typography**: Space Grotesk, DM Sans, and JetBrains Mono

## 🔬 Featured Engineering Systems

1. **Urban Heat Island Explorer**  
   Analyzed 5,000+ geospatial temperature records to identify urban heat patterns, microclimate variations, and spatial thermal anomalies using Python, Pandas, NumPy, and Folium.
   - [Repository](https://github.com/shivanianil8/urban-heat-island)

2. **FairQueue Logic Dispatcher**  
   Designed a First-Order Logic decision kernel in Prolog using Horn clauses to replace opaque priority formulas with explainable, starvation-free task dispatching.
   - [Repository](https://github.com/shivanianil8/fairqueue)

3. **Smart Traffic & Optical Scanner**  
   Computer vision pipeline utilizing OpenCV and HSV color space thresholding for real-time target bounding and spatial tracking.

4. **Vyorra E-Commerce Platform**  
   Engineered a modern e-commerce platform using the complete MERN stack (MongoDB, Express.js, React, Node.js) during a software engineering internship at Limenzy Technologies.

```bash

# 2. Install dependencies

# 3. Start local development server
npm run dev

# 4. Build for production
npm run build
```
